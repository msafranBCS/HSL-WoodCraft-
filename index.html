Important Information

LocalStorage: Reports remain available in the same browser on the same device after you close or refresh the website. They are not automatically shared with other devices or browsers.

Backups: Browser data may be lost if site data is cleared, so export a JSON backup regularly.

Privacy: This static app does not send your report data to a database or backend. PDF generation happens in your browser.

Vercel: This single index.html file can be deployed as a static site. The PDF libraries load from a CDN, so an internet connection is needed to load them for PDF features.
